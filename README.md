# مجمع عيادات أوزين الطبية | Ozen Medical Group

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fmohamedhossam237%2Fozen-web&project-name=ozen-web)

المنصة الرقمية الرسمية لمجمع عيادات أوزين الطبية في **دمياط الجديدة** — تجربة رعاية صحية فاخرة تجمع بين التصميم المعماري الحديث والتقنيات ثلاثية الأبعاد التفاعلية.

---

## 🌟 المميزات والمكونات الرئيسية

- **جناح التخصصات ثلاثي الأبعاد (3D Specialties Pavilion)**: معالج تفاعلي بتقنية Three.js يعرض أيقونات ثلاثية الأبعاد في الوقت الحقيقي مع محاكاة إضاءة ذهبية لكل تخصص طبي.
- **رحلة المريض ثلاثية الأبعاد (3D Trust & Patient Journey)**: مجسمات تفاعلية ثلاثية الأبعاد (DNA Helix, Medical Cross Core, Precision Spheres) توضح معايير الجودة والشفافية.
- **كادر الأطباء والاستشاريين**: استعراض معماري لصفوة الأطباء مع تصفية فورية حسب التخصص وبطاقات ثلاثية الأبعاد متفاعلة مع حركة المؤشر (`Card3D`).
- **الجولة الافتراضية بالمجمع**: استكشاف مرافق أوزين مع وضع فحص الصور Lightbox عالي الدقة.
- **بوابة الخدمات المتكاملة**: لوحات تحكم تجريبية للمرضى، الأطباء، موظفي الاستقبال، والإدارة.
- **حجز المواعيد الفوري**: نافذة حجز سريعة مع اختيار التخصص وتأكيد الموعد.

---

## 🛠 التقنيات المستخدمة

- **Next.js 16 (App Router + Turbopack)**
- **Three.js** للرسوميات والمجسمات ثلاثية الأبعاد WebGL
- **Tailwind CSS & Lucide Icons**
- **هوية أوزين البصرية**: ألوان وتدرجات الشعار الرسمي (Gold `#C5A059`, Deep Brown `#573F36`, Ivory `#F9F8F6`).

---

## 🚀 التشغيل المحلي (Getting Started)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
